# Security

Use the latest published source and review release notes for fixes. There is no guaranteed security support period for older releases.

For a suspected vulnerability, use the repository's **Security → Report a vulnerability** option if available. If private reporting is unavailable, open a minimal issue asking the maintainer for a private contact channel, without exploit details, recordings, tokens or sensitive data. Do not disclose sensitive reproduction details in a public issue while arranging private contact.

Include affected versions, impact and a minimal reproduction using synthetic data. Never share another person's screen contents or recordings.

Recordings and metadata are local files, not an encrypted vault. macOS account security, filesystem permissions, backups and any folders you choose for exports affect who can access them.
